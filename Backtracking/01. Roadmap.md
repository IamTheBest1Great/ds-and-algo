## The Golden Rule of Backtracking

```
choose → explore → unchoose (BACKTRACK)
```

Every backtracking solution follows this 3-step loop:
```cpp
void backtrack(state) {
    if (isComplete(state)) { recordAnswer(); return; }
    for (choice : availableChoices(state)) {
        makeChoice(choice);        // CHOOSE
        backtrack(newState);       // EXPLORE
        undoChoice(choice);        // UNCHOOSE (backtrack)
    }
}
```

## Pattern 1 — Subsets / Power Set

### Notes and Theory

**What it is**: Generate every possible subset of an array. Each element is either included or excluded. Total subsets = 2^n. The key is iterating from a `start` index to avoid revisiting earlier elements.

**How to identify**:
- "All subsets", "power set", "all subsequences"
- Output is a list of lists of varying sizes
- Keywords: "all possible subsets", "include or exclude"

**No duplicates (78)**:
```cpp
void backtrack(vector<int>& nums, int start,
               vector<int>& curr,
               vector<vector<int>>& result) {
    result.push_back(curr);           // add current subset (including empty)

    for (int i = start; i < (int)nums.size(); i++) {
        curr.push_back(nums[i]);      // CHOOSE
        backtrack(nums, i+1, curr, result); // EXPLORE (i+1: no reuse)
        curr.pop_back();              // UNCHOOSE
    }
}
// Call: backtrack(nums, 0, curr, result)
```

**With duplicates (90)**:
```cpp
void backtrack(vector<int>& nums, int start,
               vector<int>& curr,
               vector<vector<int>>& result) {
    result.push_back(curr);

    for (int i = start; i < (int)nums.size(); i++) {
        // Skip duplicate elements at the same recursion level
        if (i > start && nums[i] == nums[i-1]) continue;
        curr.push_back(nums[i]);
        backtrack(nums, i+1, curr, result);
        curr.pop_back();
    }
}
// MUST sort nums first: sort(nums.begin(), nums.end())
```

**Iterative bitmask approach** (for small n ≤ 20):
```cpp
vector<vector<int>> subsets(vector<int>& nums) {
    int n = nums.size();
    vector<vector<int>> result;
    for (int mask = 0; mask < (1 << n); mask++) {
        vector<int> subset;
        for (int i = 0; i < n; i++)
            if (mask & (1 << i)) subset.push_back(nums[i]);
        result.push_back(subset);
    }
    return result;
}
```

**Key insight**: The `start` index is what prevents picking elements before the current position, ensuring each subset is unique. For duplicates, sort first then skip `nums[i] == nums[i-1]` when `i > start` (same recursion level, not same recursive depth).

**Deduplication rule**: Skip `nums[i] == nums[i-1]` only when `i > start` (not `i > 0`). The condition `i > 0` would incorrectly skip in different branches.

## Pattern 2 — Combinations

### Notes and Theory

**What it is**: Choose a subset of elements satisfying a constraint — either exactly K elements, or elements summing to a target. Key difference from subsets: we have a specific stopping condition.

**Subpatterns**:
- **2A**: Choose exactly K from 1..n (77)
- **2B**: Combination Sum — sum to target, unlimited reuse (39)
- **2C**: Combination Sum II — sum to target, no reuse, duplicates in input (40)
- **2D**: Combination Sum III — exactly K numbers summing to n (216)

**2A — Combinations (k from 1..n) (77)**:
```cpp
void backtrack(int start, int k, int n,
               vector<int>& curr,
               vector<vector<int>>& result) {
    if ((int)curr.size() == k) { result.push_back(curr); return; }

    // Pruning: need k-curr.size() more elements, max available = n-i+1
    for (int i = start; i <= n - (k - (int)curr.size()) + 1; i++) {
        curr.push_back(i);
        backtrack(i+1, k, n, curr, result);
        curr.pop_back();
    }
}
```

**2B — Combination Sum (unlimited reuse) (39)**:
```cpp
void backtrack(vector<int>& candidates, int start, int target,
               vector<int>& curr, vector<vector<int>>& result) {
    if (target == 0) { result.push_back(curr); return; }
    if (target < 0) return; // pruning

    for (int i = start; i < (int)candidates.size(); i++) {
        if (candidates[i] > target) break; // pruning (sorted array)
        curr.push_back(candidates[i]);
        backtrack(candidates, i, target - candidates[i], curr, result); // i: reuse allowed
        curr.pop_back();
    }
}
// sort(candidates) first for pruning
```

**2C — Combination Sum II (no reuse, has duplicates) (40)**:
```cpp
void backtrack(vector<int>& candidates, int start, int target,
               vector<int>& curr, vector<vector<int>>& result) {
    if (target == 0) { result.push_back(curr); return; }

    for (int i = start; i < (int)candidates.size(); i++) {
        if (candidates[i] > target) break;               // pruning
        if (i > start && candidates[i] == candidates[i-1]) continue; // skip dups
        curr.push_back(candidates[i]);
        backtrack(candidates, i+1, target - candidates[i], curr, result); // i+1: no reuse
        curr.pop_back();
    }
}
```

**2D — Combination Sum III (39 variant)**:
```cpp
// Exactly K numbers from 1-9 summing to n
void backtrack(int start, int k, int n,
               vector<int>& curr, vector<vector<int>>& result) {
    if ((int)curr.size() == k && n == 0) { result.push_back(curr); return; }
    if ((int)curr.size() == k || n < 0) return; // pruning

    for (int i = start; i <= 9; i++) {
        curr.push_back(i);
        backtrack(i+1, k, n-i, curr, result);
        curr.pop_back();
    }
}
```

**Key insight**: The difference between **reuse** and **no-reuse** is just one character: `i` (reuse allowed) vs `i+1` (no reuse) in the recursive call. Always sort first to enable pruning with `break` when candidate > remaining target.

## Pattern 3 — Permutations

### Notes and Theory

**What it is**: Generate all ordered arrangements of elements. Unlike combinations, order matters. Use a `used[]` boolean array to track which elements are currently in the path.

**No duplicates (46)**:
```cpp
void backtrack(vector<int>& nums, vector<bool>& used,
               vector<int>& curr, vector<vector<int>>& result) {
    if ((int)curr.size() == (int)nums.size()) {
        result.push_back(curr); return;
    }

    for (int i = 0; i < (int)nums.size(); i++) {
        if (used[i]) continue;         // skip already used
        used[i] = true;
        curr.push_back(nums[i]);       // CHOOSE
        backtrack(nums, used, curr, result); // EXPLORE
        curr.pop_back();               // UNCHOOSE
        used[i] = false;
    }
}
```

**With duplicates (47)**:
```cpp
void backtrack(vector<int>& nums, vector<bool>& used,
               vector<int>& curr, vector<vector<int>>& result) {
    if ((int)curr.size() == (int)nums.size()) {
        result.push_back(curr); return;
    }

    for (int i = 0; i < (int)nums.size(); i++) {
        if (used[i]) continue;
        // Skip duplicate: same value AND previous copy not used
        // This ensures we always use the "first copy" at each level
        if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;
        used[i] = true;
        curr.push_back(nums[i]);
        backtrack(nums, used, curr, result);
        curr.pop_back();
        used[i] = false;
    }
}
// MUST sort nums first
```

**Kth Permutation (60)**:
```cpp
string getPermutation(int n, int k) {
    vector<int> factorial(n+1, 1);
    for (int i = 1; i <= n; i++) factorial[i] = factorial[i-1] * i;

    vector<int> digits;
    for (int i = 1; i <= n; i++) digits.push_back(i);

    k--; // 0-indexed
    string result = "";
    for (int i = n; i >= 1; i--) {
        int idx = k / factorial[i-1];
        result += to_string(digits[idx]);
        digits.erase(digits.begin() + idx);
        k %= factorial[i-1];
    }
    return result;
}
```

**Swap-based permutation** (alternative, no extra space):
```cpp
void backtrack(vector<int>& nums, int start, vector<vector<int>>& result) {
    if (start == (int)nums.size()) { result.push_back(nums); return; }
    for (int i = start; i < (int)nums.size(); i++) {
        swap(nums[start], nums[i]);          // CHOOSE
        backtrack(nums, start+1, result);    // EXPLORE
        swap(nums[start], nums[i]);          // UNCHOOSE
    }
}
// Note: doesn't handle duplicates cleanly — use used[] approach for duplicates
```

**Key insight**: For duplicates, the condition `!used[i-1]` ensures that among duplicate values, we always pick them in order (left to right). If the previous copy `nums[i-1]` is not used, it means we're at the same level and about to create a duplicate arrangement.

## Pattern 4 — Constraint Satisfaction

### Notes and Theory

**What it is**: Place items on a board one at a time, checking validity constraints at each step. Backtrack immediately when a placement violates any constraint. Used for board puzzles.

**How to identify**:
- Row/column/diagonal constraints
- "N-Queens", "Sudoku", "valid placement"
- Keywords: "place on board", "no two in same row/column"

**N-Queens (51)**:
```cpp
bool isValid(vector<string>& board, int row, int col, int n) {
    // Check column above
    for (int i = 0; i < row; i++)
        if (board[i][col] == 'Q') return false;
    // Check upper-left diagonal
    for (int i = row-1, j = col-1; i >= 0 && j >= 0; i--, j--)
        if (board[i][j] == 'Q') return false;
    // Check upper-right diagonal
    for (int i = row-1, j = col+1; i >= 0 && j < n; i--, j++)
        if (board[i][j] == 'Q') return false;
    return true;
}

void backtrack(vector<string>& board, int row, int n,
               vector<vector<string>>& result) {
    if (row == n) { result.push_back(board); return; }
    for (int col = 0; col < n; col++) {
        if (!isValid(board, row, col, n)) continue;
        board[row][col] = 'Q';               // CHOOSE
        backtrack(board, row+1, n, result);  // EXPLORE
        board[row][col] = '.';               // UNCHOOSE
    }
}
```

**O(1) validity check with sets**:
```cpp
set<int> cols, diag1, diag2; // diag1: row-col, diag2: row+col

bool isValid(int row, int col) {
    return !cols.count(col)
        && !diag1.count(row-col)
        && !diag2.count(row+col);
}

void place(int row, int col) {
    cols.insert(col); diag1.insert(row-col); diag2.insert(row+col);
}
void unplace(int row, int col) {
    cols.erase(col); diag1.erase(row-col); diag2.erase(row+col);
}
```

**Sudoku Solver (37)**:
```cpp
bool isValid(vector<vector<char>>& board, int row, int col, char c) {
    for (int i = 0; i < 9; i++) {
        if (board[row][i] == c) return false;           // same row
        if (board[i][col] == c) return false;           // same col
        int r = 3*(row/3) + i/3, k = 3*(col/3) + i%3;
        if (board[r][k] == c) return false;             // same 3x3 box
    }
    return true;
}

bool solve(vector<vector<char>>& board) {
    for (int r = 0; r < 9; r++) {
        for (int c = 0; c < 9; c++) {
            if (board[r][c] != '.') continue;
            for (char ch = '1'; ch <= '9'; ch++) {
                if (!isValid(board, r, c, ch)) continue;
                board[r][c] = ch;                // CHOOSE
                if (solve(board)) return true;   // EXPLORE
                board[r][c] = '.';               // UNCHOOSE
            }
            return false; // no valid digit found — backtrack
        }
    }
    return true; // all cells filled
}
```

**Key insight**: Return `false` when no valid choice exists — this triggers backtracking in the parent call. Return `true` when complete. Constraint checking before recursion is key — the more you prune, the faster it runs.

## Pattern 5 — Word Search / Grid Backtracking

### Notes and Theory

**What it is**: Explore a 2D grid by DFS, marking cells as visited during exploration and unmarking them on backtrack. Used for word search, path finding with all cells visited, and maze solving.

**How to identify**:
- "Does word exist on grid?", "find all paths on grid"
- Must visit cells without revisiting in the current path
- Keywords: "grid", "board", "word exists", "path visits all cells"

**Word Search (79)**:
```cpp
bool backtrack(vector<vector<char>>& board, string& word,
               int idx, int r, int c) {
    if (idx == (int)word.size()) return true;  // found complete word
    if (r<0 || r>=(int)board.size() ||
        c<0 || c>=(int)board[0].size()) return false;
    if (board[r][c] != word[idx]) return false;

    char temp = board[r][c];
    board[r][c] = '#';  // CHOOSE — mark visited in-place

    int dirs[4][2] = {{0,1},{0,-1},{1,0},{-1,0}};
    for (auto& d : dirs) {
        if (backtrack(board, word, idx+1, r+d[0], c+d[1]))
            return true; // found — no need to restore
    }

    board[r][c] = temp; // UNCHOOSE — restore
    return false;
}

bool exist(vector<vector<char>>& board, string word) {
    for (int r = 0; r < (int)board.size(); r++)
        for (int c = 0; c < (int)board[0].size(); c++)
            if (backtrack(board, word, 0, r, c)) return true;
    return false;
}
```

**Word Search II — Trie + Backtracking (212)**:
```cpp
// Insert all words into a Trie
// DFS on grid, walk Trie simultaneously
// When TrieNode.word != "", we found a word — record it
// Prune: if no Trie child exists for current char, stop

void dfs(vector<vector<char>>& board, TrieNode* node,
         int r, int c, vector<string>& result) {
    if (r<0||r>=(int)board.size()||c<0||c>=(int)board[0].size()) return;
    char ch = board[r][c];
    if (ch == '#' || !node->children[ch-'a']) return; // pruning

    node = node->children[ch-'a'];
    if (!node->word.empty()) {
        result.push_back(node->word);
        node->word = ""; // avoid duplicates
    }

    board[r][c] = '#';
    for (auto [dr, dc] : dirs) dfs(board, node, r+dr, c+dc, result);
    board[r][c] = ch;
}
```

**Unique Paths III (980) — visit ALL cells**:
```cpp
// Must visit every non-obstacle cell exactly once
// State: (row, col, remaining cells to visit)
// When remaining == 0 AND at end: count++
int backtrack(vector<vector<int>>& grid, int r, int c, int remaining) {
    if (grid[r][c] == 2) return remaining == 0 ? 1 : 0;
    int temp = grid[r][c];
    grid[r][c] = -1; // mark visited
    int paths = 0;
    for (auto [dr, dc] : dirs) {
        int nr = r+dr, nc = c+dc;
        if (valid(nr,nc) && grid[nr][nc] != -1)
            paths += backtrack(grid, nr, nc, remaining-1);
    }
    grid[r][c] = temp; // restore
    return paths;
}
```

**Key insight**: Mark cells visited by temporarily changing their value (e.g., to `'#'`). This avoids a separate visited array and automatically unmarks on backtrack when you restore the original value.

## Pattern 6 — Palindrome / String Partitioning

### Notes and Theory

**What it is**: Split a string into parts satisfying a condition (all palindromes, all valid words, valid IP segments). At each position, try all valid prefix lengths as the next "cut."

**How to identify**:
- "All ways to split string into valid parts"
- "Palindrome partitioning", "restore IP addresses"
- Keywords: "partition", "split into", "all ways to divide"

**Palindrome Partitioning (131)**:
```cpp
// Precompute isPalin[i][j] to avoid O(n) check in backtracking
vector<vector<bool>> isPalin;

void precompute(string& s) {
    int n = s.size();
    isPalin.assign(n, vector<bool>(n, false));
    for (int i = n-1; i >= 0; i--) {
        for (int j = i; j < n; j++) {
            if (s[i] == s[j] && (j-i <= 2 || isPalin[i+1][j-1]))
                isPalin[i][j] = true;
        }
    }
}

void backtrack(string& s, int start,
               vector<string>& curr,
               vector<vector<string>>& result) {
    if (start == (int)s.size()) { result.push_back(curr); return; }

    for (int end = start; end < (int)s.size(); end++) {
        if (!isPalin[start][end]) continue; // pruning
        curr.push_back(s.substr(start, end-start+1));
        backtrack(s, end+1, curr, result);
        curr.pop_back();
    }
}
```

**Restore IP Addresses (93)**:
```cpp
void backtrack(string& s, int start, int part,
               vector<string>& curr, vector<string>& result) {
    if (part == 4 && start == (int)s.size()) {
        result.push_back(curr[0]+"."+curr[1]+"."+curr[2]+"."+curr[3]);
        return;
    }
    if (part == 4 || start == (int)s.size()) return;

    for (int len = 1; len <= 3; len++) {
        if (start + len > (int)s.size()) break;
        string seg = s.substr(start, len);
        // Pruning: no leading zeros, value <= 255
        if (seg.size() > 1 && seg[0] == '0') break;
        if (stoi(seg) > 255) break;
        curr.push_back(seg);
        backtrack(s, start+len, part+1, curr, result);
        curr.pop_back();
    }
}
```

**Word Break II (140) — all valid sentences**:
```cpp
unordered_set<string> dict;
unordered_map<int, vector<string>> memo;

vector<string> backtrack(string& s, int start) {
    if (memo.count(start)) return memo[start];
    if (start == (int)s.size()) return {""};

    vector<string> result;
    for (int end = start+1; end <= (int)s.size(); end++) {
        string word = s.substr(start, end-start);
        if (!dict.count(word)) continue;
        for (string& rest : backtrack(s, end)) {
            result.push_back(word + (rest.empty() ? "" : " ") + rest);
        }
    }
    return memo[start] = result;
}
```

**Key insight**: Precomputing palindrome table or using memoization dramatically speeds up string partitioning. Without it, naive backtracking is O(n × 2^n). With precomputed `isPalin`, it becomes O(2^n) for generation which is tight but acceptable.

## Pattern 7 — Expression / Operator Insertion

### Notes and Theory

**What it is**: Insert operators (+, -, *, /) between digits or numbers to generate all valid expressions or reach a target value. Must handle operator precedence (multiplication changes running value).

**How to identify**:
- "Add operators between digits", "evaluate all expressions"
- Keywords: "operators", "expressions", "between digits", "target value"

**Expression Add Operators (282)**:
```cpp
void backtrack(string& num, int target, int start,
               long long eval, long long mult,
               string curr, vector<string>& result) {
    if (start == (int)num.size()) {
        if (eval == target) result.push_back(curr);
        return;
    }

    for (int len = 1; len <= (int)num.size() - start; len++) {
        string part = num.substr(start, len);
        // Pruning: no leading zeros except "0" itself
        if (part.size() > 1 && part[0] == '0') break;
        long long val = stoll(part);

        if (start == 0) {
            // First number: no operator before it
            backtrack(num, target, len, val, val, part, result);
        } else {
            // Addition: eval + val
            backtrack(num, target, start+len, eval+val, val,
                      curr+"+"+part, result);
            // Subtraction: eval - val
            backtrack(num, target, start+len, eval-val, -val,
                      curr+"-"+part, result);
            // Multiplication: undo last addition, multiply
            // mult is the last term added/subtracted
            backtrack(num, target, start+len,
                      eval - mult + mult*val, mult*val,
                      curr+"*"+part, result);
        }
    }
}
```

**Why track `mult`?** Multiplication has higher precedence. If the previous operation was `+3` (mult=3) and now we multiply by 5, the correct new total is: `eval - mult + mult*5` (undo the +3, add 3*5 instead).

**24 Game (679)**:
```cpp
// Try all permutations of 4 numbers × all combinations of 3 operators
// Check if any equals 24.0 (use floating point with epsilon)
bool solve24(vector<double>& nums) {
    if (nums.size() == 1) return fabs(nums[0] - 24.0) < 1e-6;
    for (int i = 0; i < (int)nums.size(); i++) {
        for (int j = 0; j < (int)nums.size(); j++) {
            if (i == j) continue;
            vector<double> next;
            for (int k = 0; k < (int)nums.size(); k++)
                if (k != i && k != j) next.push_back(nums[k]);
            for (double result : applyOps(nums[i], nums[j])) {
                next.push_back(result);
                if (solve24(next)) return true;
                next.pop_back();
            }
        }
    }
    return false;
}

vector<double> applyOps(double a, double b) {
    return {a+b, a-b, a*b, b != 0 ? a/b : 1e18};
}
```

## Pattern 8 — Path Enumeration on Graphs / Trees

### Notes and Theory

**What it is**: Find ALL paths from source to destination in a directed graph or tree. Use DFS with a `visited` array (or in-place marking) to avoid cycles.

**How to identify**:
- "All paths from source to target"
- "All root-to-leaf paths"
- Keywords: "all paths", "enumerate paths", "find every route"

**All Paths Source to Target (797) — DAG**:
```cpp
void dfs(vector<vector<int>>& graph, int node, int target,
         vector<int>& path, vector<vector<int>>& result) {
    path.push_back(node);
    if (node == target) { result.push_back(path); }
    else {
        for (int next : graph[node]) {
            dfs(graph, next, target, path, result);
        }
    }
    path.pop_back(); // BACKTRACK
}
// DAG: no need for visited array (no cycles by definition)
```

**All paths in general graph (with cycles)**:
```cpp
void dfs(vector<vector<int>>& adj, int node, int target,
         vector<int>& path, vector<bool>& visited,
         vector<vector<int>>& result) {
    visited[node] = true;
    path.push_back(node);

    if (node == target) result.push_back(path);
    else {
        for (int next : adj[node]) {
            if (!visited[next])
                dfs(adj, next, target, path, visited, result);
        }
    }

    path.pop_back();
    visited[node] = false; // BACKTRACK — unmark visited
}
```

**All Root-to-Leaf Paths (257)**:
```cpp
void dfs(TreeNode* node, string path, vector<string>& result) {
    if (!node) return;
    path += to_string(node->val);
    if (!node->left && !node->right) { result.push_back(path); return; }
    path += "->";
    dfs(node->left, path, result);
    dfs(node->right, path, result);
    // String passed by value: automatic backtracking
}
```

**Key insight**: In a DAG, no visited array is needed — no cycles possible. In general graphs, `visited[node] = false` on backtrack is essential, otherwise later paths won't explore through this node.

## Pattern 9 — Generate Structures

### Notes and Theory

**What it is**: Build valid strings or structures character by character with explicit count constraints. No "unchoosing" in the traditional sense — instead, you pass updated counts as parameters.

**How to identify**:
- "Generate all valid parentheses", "letter combinations of phone number"
- Output strings of fixed or variable length satisfying a property
- Keywords: "generate all valid", "all combinations of characters"

**Generate Parentheses (22)**:
```cpp
void backtrack(int open, int close, int n,
               string curr, vector<string>& result) {
    if ((int)curr.size() == 2*n) { result.push_back(curr); return; }

    if (open < n) {
        backtrack(open+1, close, n, curr+"(", result); // add open
    }
    if (close < open) {
        backtrack(open, close+1, n, curr+")", result); // add close
    }
}
// Call: backtrack(0, 0, n, "", result)
// Invariant: close <= open <= n (always valid prefix)
```

**Letter Combinations of Phone Number (17)**:
```cpp
void backtrack(string& digits, int idx,
               string curr, vector<string>& result,
               unordered_map<char,string>& phoneMap) {
    if (idx == (int)digits.size()) { result.push_back(curr); return; }
    for (char c : phoneMap[digits[idx]]) {
        backtrack(digits, idx+1, curr+c, result, phoneMap);
    }
}
```

**Letter Case Permutation (784)**:
```cpp
void backtrack(string& s, int idx, vector<string>& result) {
    if (idx == (int)s.size()) { result.push_back(s); return; }
    backtrack(s, idx+1, result); // keep as is
    if (isalpha(s[idx])) {
        s[idx] ^= 32; // toggle case
        backtrack(s, idx+1, result);
        s[idx] ^= 32; // restore
    }
}
```

**Key insight**: The constraint `close < open` for parentheses is the validity check. Passing `open` and `close` counts avoids needing to validate the entire string. This is more efficient than generating all strings and filtering.

## Pattern 10 — Pruning-Heavy / Optimization Backtracking

### Notes and Theory

**What it is**: Backtracking where aggressive pruning is the key to feasibility. Often involves assigning items to bins/groups with capacity constraints. Without pruning, these problems would time out.

**How to identify**:
- "Minimum number of groups/sessions/bins"
- "Fair distribution", "assign tasks with constraints"
- Keywords: "minimum bins", "fair distribution", "work sessions"

**Minimum Work Sessions (1986)**:
```cpp
int result = INT_MAX;

void backtrack(vector<int>& tasks, vector<int>& sessions,
               int idx, int sessionTime) {
    if (idx == (int)tasks.size()) {
        // Count non-empty sessions
        result = min(result, (int)count_if(sessions.begin(),
                     sessions.end(), [](int x){ return x > 0; }));
        return;
    }
    // Pruning: current session count already >= result
    int used = count_if(sessions.begin(), sessions.end(),
                        [](int x){ return x > 0; });
    if (used >= result) return;

    set<int> tried; // avoid duplicate session sizes
    for (int i = 0; i < (int)sessions.size(); i++) {
        if (tried.count(sessions[i])) continue; // dedup
        if (sessions[i] + tasks[idx] <= sessionTime) {
            tried.insert(sessions[i]);
            sessions[i] += tasks[idx];
            backtrack(tasks, sessions, idx+1, sessionTime);
            sessions[i] -= tasks[idx];
        }
    }
}
```

**Fair Distribution of Cookies (2305)**:
```cpp
int result = INT_MAX;

void backtrack(vector<int>& cookies, vector<int>& children,
               int idx) {
    if (idx == (int)cookies.size()) {
        result = min(result, *max_element(children.begin(), children.end()));
        return;
    }
    set<int> tried;
    for (int i = 0; i < (int)children.size(); i++) {
        if (tried.count(children[i])) continue; // dedup identical children
        if (children[i] + cookies[idx] >= result) continue; // pruning
        tried.insert(children[i]);
        children[i] += cookies[idx];
        backtrack(cookies, children, idx+1);
        children[i] -= cookies[idx];
    }
}
// Sort cookies descending for better pruning
```

**Key pruning strategies**:
1. **Upper bound pruning**: if current partial solution already exceeds best, stop
2. **Symmetry pruning**: skip identical states (tried set for same-valued bins)
3. **Sort first**: process largest items first to prune dead ends early
4. **Empty bin dedup**: multiple empty bins are equivalent — only try one

## Quick Reference — Common Mistakes

| Mistake | Correct Approach |
|---|---|
| Forgetting `curr.pop_back()` after recursive call | Every `push_back` must have a matching `pop_back` — the backtrack step |
| Dedup: using `i > 0` instead of `i > start` for subsets | `i > start` skips dups at same level only — `i > 0` incorrectly skips across levels |
| Permutation dedup: using `!used[i-1]` without sorting | MUST sort array first — `nums[i] == nums[i-1]` only works on sorted input |
| Combination Sum: not sorting before using `break` | Sort candidates first — `break` when `candidates[i] > target` relies on sorted order |
| Grid backtrack: not restoring cell after DFS | Must restore `board[r][c] = temp` after recursive calls |
| Expression operators: not tracking `mult` for `*` | `eval - mult + mult*val` is the correct multiplication update |
| N-Queens: only checking same column, missing diagonals | Check all three: column, upper-left diagonal, upper-right diagonal |
| Sudoku: wrong 3x3 box index | Box index: `row = 3*(r/3) + i/3`, `col = 3*(c/3) + i%3` |
| Not pruning in optimization backtracking | Always check `if (current >= best) return` before exploring |
| Word Search: using separate visited array | Mark in-place `board[r][c] = '#'` — simpler and avoids extra space |
