## Pattern 1 — Basic Prefix Sum (Range Query)

### 📖 Notes & Theory

**What it is**: Precompute a prefix array where `prefix[i]` = sum of all elements from index `0` to `i-1`. Any range sum `[l, r]` is then answered in O(1) as `prefix[r+1] - prefix[l]`. Converts O(n) per query to O(1) per query after O(n) preprocessing.

**How to identify**:
- Multiple range sum queries on a static array
- "Sum of elements from index l to r"
- "Subarray sum", "range sum", "cumulative sum"
- Keywords: "sum between", "total from l to r", "query"

**Building prefix sum**:
```cpp
vector<int> prefix(n + 1, 0);
for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + nums[i];
}
// prefix[i] = sum of nums[0..i-1]
// rangeSum(l, r) = prefix[r+1] - prefix[l]   (0-indexed, inclusive)
```

**Key formula**:
```
rangeSum(l, r) = prefix[r + 1] - prefix[l]
```

**Why size n+1?** `prefix[0] = 0` acts as a sentinel. This lets you compute `rangeSum(0, r)` without a special case — it's just `prefix[r+1] - prefix[0] = prefix[r+1]`.

**Product variant (238)**:
```cpp
// prefix[i] = product of nums[0..i-1]
// suffix[i] = product of nums[i+1..n-1]
// result[i] = prefix[i] * suffix[i]
```

**Max subarray sum variant** — prefix min tracking:
```cpp
// maxSubarraySum = max over all r of (prefix[r+1] - min(prefix[0..r]))
int minPrefix = 0, maxSum = INT_MIN;
for (int i = 0; i < n; i++) {
    maxSum = max(maxSum, prefix[i + 1] - minPrefix);
    minPrefix = min(minPrefix, prefix[i + 1]);
}
```

**Key insight**: Every subarray sum `[l, r]` = `prefix[r+1] - prefix[l]`. Thinking in terms of "two prefix values" is the key mental model for all prefix sum patterns.

## Pattern 2 — Prefix Sum + HashMap (Subarray Sum = K)

### 📖 Notes & Theory

**What it is**: The most powerful and most asked prefix sum pattern. To count subarrays with sum exactly equal to `k`, use a hashmap that stores how many times each prefix sum value has been seen. For each new prefix sum, look up `prefixSum - k` in the map.

**How to identify**:
- "Number of subarrays with sum = K"
- "Find a subarray with sum equal to target"
- "Longest subarray with sum = K"
- Keywords: "count subarrays", "sum equals", "subarray sum k"

**Count subarrays with sum = K (560)**:
```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> prefixCount;
    prefixCount[0] = 1; // empty prefix
    int prefixSum = 0, count = 0;

    for (int x : nums) {
        prefixSum += x;
        // If (prefixSum - k) was seen before, those subarrays sum to k
        count += prefixCount[prefixSum - k];
        prefixCount[prefixSum]++;
    }
    return count;
}
```

**Why `prefixCount[0] = 1`?** Handles the case where the subarray starting from index 0 has sum exactly k (i.e., `prefixSum - k = 0`).

**Longest subarray with sum = K**:
```cpp
unordered_map<int, int> firstSeen; // prefixSum → first index
firstSeen[0] = -1;
int prefixSum = 0, maxLen = 0;

for (int i = 0; i < n; i++) {
    prefixSum += nums[i];
    if (firstSeen.count(prefixSum - k)) {
        maxLen = max(maxLen, i - firstSeen[prefixSum - k]);
    }
    if (!firstSeen.count(prefixSum)) {
        firstSeen[prefixSum] = i; // only record FIRST occurrence
    }
}
```

**Key insight**: `subarray[l..r] sum = k` ⟺ `prefix[r+1] - prefix[l] = k` ⟺ `prefix[l] = prefix[r+1] - k`. So for each `r`, we ask: "how many previous prefix values equal `prefixSum - k`?" The hashmap answers this in O(1).

**Two-sum analogy**: This is exactly Two Sum — for each element, look up its complement in the map. The prefix sum IS the element; `k` is the target.

## Pattern 3 — Prefix Sum on 2D Matrix

### 📖 Notes & Theory

**What it is**: Extend 1D prefix sums to a 2D grid. `prefix[i][j]` = sum of all elements in the rectangle from `(0,0)` to `(i-1, j-1)`. Any submatrix sum is computed in O(1) using the inclusion-exclusion formula.

**How to identify**:
- "Sum of submatrix from (r1,c1) to (r2,c2)"
- "Count submatrices with sum = target"
- "Max sum rectangle"
- Keywords: "submatrix", "rectangle sum", "2D range query", "grid sum"

**Building 2D prefix sum**:
```cpp
// prefix[i][j] = sum of rectangle (0,0) to (i-1,j-1)
vector<vector<int>> prefix(m + 1, vector<int>(n + 1, 0));

for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        prefix[i][j] = matrix[i-1][j-1]
                     + prefix[i-1][j]      // above
                     + prefix[i][j-1]      // left
                     - prefix[i-1][j-1];   // subtract double-counted corner
    }
}
```

**Submatrix sum query**:
```cpp
// Sum of rectangle (r1,c1) to (r2,c2) — 0-indexed
int rectSum(int r1, int c1, int r2, int c2) {
    return prefix[r2+1][c2+1]
         - prefix[r1][c2+1]    // remove top
         - prefix[r2+1][c1]    // remove left
         + prefix[r1][c1];     // add back double-subtracted corner
}
```

**Count submatrices with sum = target (1074)**:
```cpp
// Fix top and bottom row, compress columns into 1D prefix sum
// Then use Pattern 2 (prefix + hashmap) on the 1D column sums
for (int r1 = 0; r1 < m; r1++) {
    vector<int> colSum(n, 0);
    for (int r2 = r1; r2 < m; r2++) {
        for (int c = 0; c < n; c++) colSum[c] += matrix[r2][c];
        // Now apply 560-style prefix+hashmap on colSum for target
        unordered_map<int, int> seen{{0, 1}};
        int prefSum = 0;
        for (int s : colSum) {
            prefSum += s;
            count += seen[prefSum - target];
            seen[prefSum]++;
        }
    }
}
```

**Key insight**: The 2D inclusion-exclusion formula is `A + B - C - D` where A is the full prefix, B and C are the strips removed, and D is the corner added back. Memorize this as "full − top − left + corner."

## Pattern 4 — Difference Array (Range Update)

### 📖 Notes & Theory

**What it is**: The **inverse** of prefix sum. Instead of querying ranges, you **update** ranges efficiently. A difference array `diff[i]` stores the change at position `i`. After all updates, take the prefix sum of `diff` to get the final array. Each range update is O(1); reconstructing the final array is O(n).

**How to identify**:
- "Add value X to all elements in range [l, r]"
- "Increment a range multiple times, find final array"
- "Count overlapping intervals at each point"
- Keywords: "range update", "add to range", "overlap count", "increment interval"

**Difference array construction and update**:
```cpp
vector<int> diff(n + 1, 0); // size n+1 for boundary safety

// Range update: add val to [l, r] (0-indexed, inclusive)
auto update = [&](int l, int r, int val) {
    diff[l] += val;
    diff[r + 1] -= val;
};

// Reconstruct final array via prefix sum of diff
vector<int> result(n);
int running = 0;
for (int i = 0; i < n; i++) {
    running += diff[i];
    result[i] = running;
}
```

**Count overlapping intervals (meeting rooms, car pooling)**:
```cpp
// For each interval [start, end], add 1 at start, subtract 1 at end+1
// Prefix sum of diff = number of active intervals at each point
for (auto& [start, end] : intervals) {
    diff[start]++;
    diff[end + 1]--;
}
// prefix sum → active[i] = number of intervals covering point i
```

**Key insight**: Difference array = O(1) updates + O(n) reconstruction. Prefix sum = O(n) build + O(1) queries. They are mathematical inverses — diff is the "derivative" and prefix sum is the "integral."

**When to use diff array vs segment tree**: Use diff array when ALL updates come before ALL queries (offline). Use segment tree when updates and queries are interleaved (online).

## Pattern 5 — Prefix XOR

### 📖 Notes & Theory

**What it is**: XOR has a special property — `a XOR a = 0`. This means `prefix[r+1] XOR prefix[l]` = XOR of all elements in `[l, r]`. Exactly mirrors prefix sum but with XOR instead of addition.

**How to identify**:
- "XOR of elements in range [l, r]"
- "Count subarrays with XOR = K"
- "Find subarray with XOR equal to target"
- Keywords: "XOR query", "XOR of subarray", "bitwise XOR range"

**Building prefix XOR**:
```cpp
vector<int> prefXOR(n + 1, 0);
for (int i = 0; i < n; i++) {
    prefXOR[i + 1] = prefXOR[i] ^ nums[i];
}
// XOR of range [l, r] = prefXOR[r+1] ^ prefXOR[l]
```

**Count subarrays with XOR = K (1442 / general)**:
```cpp
// Same as Pattern 2 but with XOR and hashmap
unordered_map<int, int> seen;
seen[0] = 1;
int prefXOR = 0, count = 0;

for (int x : nums) {
    prefXOR ^= x;
    count += seen[prefXOR ^ k]; // looking for prefix that XORs with k
    seen[prefXOR]++;
}
```

**Why `prefXOR ^ k`?** We want `prefXOR[r+1] ^ prefXOR[l] = k`, which means `prefXOR[l] = prefXOR[r+1] ^ k`. So look up `currentXOR ^ k` in the hashmap.

**XOR triplets (1442)**:
```cpp
// If XOR of [i+1..j] == XOR of [j+1..k] then XOR of [i+1..k] == 0
// Count pairs where prefXOR[i] == prefXOR[k+1]
// Use hashmap of prefXOR value → list of indices
```

**Key insight**: Every XOR prefix sum property mirrors the additive prefix sum. The only change is replacing `+` with `^` and `-` with `^` (since `a ^ a = 0`, subtraction = XOR in this world).

## Pattern 6 — Prefix Sum + Binary Search

### 📖 Notes & Theory

**What it is**: The prefix sum array is **sorted** (when all elements are non-negative), which allows binary search on it. Used to find the leftmost/rightmost position satisfying a sum condition, or for weighted random sampling.

**How to identify**:
- "Find the leftmost index where prefix sum ≥ target"
- "Random pick weighted by probability"
- "Find shortest subarray with sum ≥ target" (when values are positive)
- Keywords: "weighted random", "kth prefix", "first position with sum"

**Weighted Random Pick (528)**:
```cpp
class Solution {
    vector<int> prefix;
public:
    Solution(vector<int>& w) {
        prefix.resize(w.size());
        prefix[0] = w[0];
        for (int i = 1; i < w.size(); i++) prefix[i] = prefix[i-1] + w[i];
    }

    int pickIndex() {
        int target = rand() % prefix.back() + 1; // random in [1, total]
        // Binary search for leftmost prefix[i] >= target
        return lower_bound(prefix.begin(), prefix.end(), target) - prefix.begin();
    }
};
```

**Shortest subarray with sum ≥ K (positive numbers only)**:
```cpp
// prefix is sorted (all positive) → binary search for prefix[j] >= prefix[i] + k
for (int i = 0; i < n; i++) {
    auto it = lower_bound(prefix.begin() + i + 1, prefix.end(), prefix[i] + k);
    if (it != prefix.end()) minLen = min(minLen, (int)(it - prefix.begin()) - i);
}
```

**Kth Missing Positive (1539)**:
```cpp
// f(x) = number of missing positives up to x = x - count(elements ≤ x)
// Binary search on x for f(x) == k
// count(elements ≤ x) = upper_bound(arr, x) - arr.begin()
```

**Key insight**: Prefix sums of non-negative arrays are non-decreasing, making them valid inputs for binary search. This unlocks O(log n) range queries when you need the boundary rather than the value.

## Pattern 7 — Running Balance / Equilibrium

### 📖 Notes & Theory

**What it is**: Find a position where the array is "balanced" — left sum equals right sum, or some property holds between the prefix and suffix. Computed in O(n) with a running sum from the left and comparing with the total.

**How to identify**:
- "Find pivot index where left sum = right sum"
- "Split array into two parts with equal sum"
- "Find index where left product = right product"
- Keywords: "equal halves", "pivot", "equilibrium", "balanced split", "left equals right"

**Pivot index (724)**:
```cpp
int pivotIndex(vector<int>& nums) {
    int total = 0;
    for (int x : nums) total += x;

    int leftSum = 0;
    for (int i = 0; i < nums.size(); i++) {
        // rightSum = total - leftSum - nums[i]
        if (leftSum == total - leftSum - nums[i]) return i;
        leftSum += nums[i];
    }
    return -1;
}
```

**Number of ways to split array (2270)**:
```cpp
// Count indices i where prefix[i+1] >= suffix[i+1]
// suffix[i] = total - prefix[i]
long long total = 0;
for (int x : nums) total += x;

long long prefSum = 0, count = 0;
for (int i = 0; i < n - 1; i++) { // don't include last index (right must be non-empty)
    prefSum += nums[i];
    if (prefSum >= total - prefSum) count++;
}
```

**Maximum difference score (running min/max)**:
```cpp
// Track running minimum from left
// For each j: best gain = nums[j] - min(nums[0..j-1])
int runMin = nums[0], maxGain = INT_MIN;
for (int j = 1; j < n; j++) {
    maxGain = max(maxGain, nums[j] - runMin);
    runMin = min(runMin, nums[j]);
}
```

**Key insight**: Instead of building the full prefix and suffix arrays, maintain a `leftSum` variable and compute `rightSum = total - leftSum - currentElement` on the fly. This gives O(1) space.

## Pattern 8 — Prefix Sum on Strings / Characters

### 📖 Notes & Theory

**What it is**: Apply prefix sums to **string properties** — character frequencies, vowel counts, or boolean attributes (is this character a vowel?). Build a prefix count array for each character, then answer range queries in O(1).

**How to identify**:
- "Count vowels in substring [l, r]"
- "Check if substring can be rearranged to palindrome"
- "Number of characters satisfying condition in range"
- Keywords: "count in range", "substring query", "character frequency range"

**Prefix count of vowels (1456)**:
```cpp
string vowels = "aeiouAEIOU";
auto isVowel = [&](char c) { return vowels.find(c) != string::npos; };

vector<int> prefix(s.size() + 1, 0);
for (int i = 0; i < s.size(); i++) {
    prefix[i + 1] = prefix[i] + isVowel(s[i]);
}
// vowels in [l, r] = prefix[r+1] - prefix[l]
```

**Can make palindrome from substring (1177)** — prefix XOR of character bits:
```cpp
// For each character c, maintain prefix XOR of (1 << (c - 'a'))
// A substring can form a palindrome if at most 1 character has odd frequency
// prefXOR[r+1] ^ prefXOR[l] has at most 1 bit set (after allowing k replacements)
vector<int> prefXOR(n + 1, 0);
for (int i = 0; i < n; i++) {
    prefXOR[i + 1] = prefXOR[i] ^ (1 << (s[i] - 'a'));
}
// For query [l, r]: xorVal = prefXOR[r+1] ^ prefXOR[l]
// Count set bits in xorVal → odd-frequency chars
// Can form palindrome if setbits <= 1 + 2*k (k replacements)
```

**Prefix count array for each character (26 arrays)**:
```cpp
// prefix[c][i] = count of character c in s[0..i-1]
vector<array<int, 26>> prefix(n + 1, array<int,26>{});
for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i];
    prefix[i + 1][s[i] - 'a']++;
}
// count of char c in [l, r] = prefix[r+1][c] - prefix[l][c]
```

**Key insight**: Strings are just arrays of characters. Any numeric property of characters (is vowel → 0/1, character index → 0-25) can be prefix-summed the same way as numbers.

## Pattern 9 — Modular Prefix Sum

### 📖 Notes & Theory

**What it is**: Apply modular arithmetic to prefix sums. The key insight: `(prefix[r+1] - prefix[l]) % k == 0` ⟺ `prefix[r+1] % k == prefix[l] % k`. So count pairs with equal remainders using a hashmap of remainder → count.

**How to identify**:
- "Subarray sum divisible by K"
- "Number of subarrays with sum ≡ 0 (mod K)"
- "Continuous subarray sum that is a multiple of K"
- Keywords: "divisible by K", "multiple of", "modulo", "remainder"

**Subarray sums divisible by K (974)**:
```cpp
int subarraysDivByK(vector<int>& nums, int k) {
    unordered_map<int, int> remainderCount;
    remainderCount[0] = 1; // empty prefix has remainder 0
    int prefSum = 0, count = 0;

    for (int x : nums) {
        prefSum += x;
        int rem = ((prefSum % k) + k) % k; // handle negative numbers!
        count += remainderCount[rem];
        remainderCount[rem]++;
    }
    return count;
}
```

**Why `(prefSum % k + k) % k`?** In C++, the `%` operator can return negative values for negative numbers. Adding `k` before taking `% k` again ensures the remainder is always non-negative.

**Continuous subarray sum (multiple of k) (523)**:
```cpp
// At least length 2 → ensure j - i >= 2, i.e., i was seen at least 2 steps ago
unordered_map<int, int> firstSeen;
firstSeen[0] = -1; // empty prefix at index -1
int prefSum = 0;

for (int i = 0; i < n; i++) {
    prefSum += nums[i];
    int rem = ((prefSum % k) + k) % k;
    if (firstSeen.count(rem)) {
        if (i - firstSeen[rem] >= 2) return true; // length check
    } else {
        firstSeen[rem] = i; // store FIRST occurrence only
    }
}
return false;
```

**Key insight**: Two prefix sums with the same remainder means the subarray between them is divisible by K. This turns a divisibility problem into an equality problem — exactly like Pattern 2 but with `%` applied to both sides.

## Pattern 10 — Higher Dimension / Advanced Prefix

### 📖 Notes & Theory

**What it is**: Prefix sums applied to trees (path sums), 3D grids, or multi-dimensional problems. Also covers cases where multiple prefix arrays interact, or where prefix sums are combined with other data structures like segment trees or Fenwick trees.

**How to identify**:
- "Path sum in tree from root to node" (tree prefix sum)
- "3D range sum query"
- "Sum of all subarray sums" (contribution technique)
- "Prefix sum on difference array of prefix sums"

**Tree prefix sum (path sum from root)**:
```cpp
// DFS carries running prefix sum from root
// At each node, prefixSum = sum of all values from root to current node
// For path sum problems: use hashmap of prefixSum values (Pattern 2 on tree)
void dfs(TreeNode* node, int prefSum, unordered_map<int,int>& seen, int& ans, int k) {
    if (!node) return;
    prefSum += node->val;
    ans += seen[prefSum - k];  // count paths ending here with sum k
    seen[prefSum]++;
    dfs(node->left, prefSum, seen, ans, k);
    dfs(node->right, prefSum, seen, ans, k);
    seen[prefSum]--;           // backtrack
}
// Initialize: seen[0] = 1
```

**Sum of all subarray sums (contribution)**:
```cpp
// Each element nums[i] appears in subarrays starting at 0..i and ending at i..n-1
// Contribution of nums[i] = nums[i] * (i + 1) * (n - i)
long long totalSum = 0;
for (int i = 0; i < n; i++) {
    totalSum += (long long)nums[i] * (i + 1) * (n - i);
}
```

**Prefix sum of prefix sums**:
```cpp
// prefix2[i] = sum of prefix[0..i] = sum of all subarrays ending at each index
// Used in problems asking for sum of all subarray sums up to index i
```

**Key insight**: Tree prefix sums work identically to array prefix sums — the "array" is the path from root to node, and backtracking undoes the prefix contribution when leaving a subtree.

## Quick Reference — Common Mistakes

| Mistake | Correct Approach |
|---|---|
| Building prefix array of size n instead of n+1 | Always use size `n+1`; `prefix[0] = 0` is the essential sentinel |
| Forgetting `prefixCount[0] = 1` in hashmap | Without it, subarrays starting at index 0 are missed |
| Range sum formula off-by-one | `rangeSum(l, r) = prefix[r+1] - prefix[l]` — both inclusive, 0-indexed |
| 2D formula wrong sign | `prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]` |
| Negative modulo in C++ | Always use `((x % k) + k) % k` to ensure non-negative remainder |
| Difference array: off-by-one at right boundary | `diff[r+1] -= val` NOT `diff[r] -= val` — effect ends AFTER index r |
| Longest subarray: storing latest index instead of first | For longest, store FIRST occurrence; for counting, store ALL occurrences |
| Prefix XOR: using subtraction instead of XOR | XOR is its own inverse: `a ^ b ^ b = a`; use `^` for both combine and undo |
| Tree prefix sum: forgetting to backtrack | After both recursive calls, `seen[prefSum]--` to undo the current node |
| Using int instead of long long | Prefix sums of large arrays overflow int — use `long long` for safety |
