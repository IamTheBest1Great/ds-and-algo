## 🟢 PATTERN 1: Parentheses / Bracket Processing

### 🔹 Sub-pattern 1A: Basic Validation

**Mental model**

* Stack stores **unmatched opening brackets**
* Each closing bracket must match the **latest opening** → LIFO

**Recognition**

* “valid parentheses”
* “balanced brackets”
* “proper nesting”

**Template**

```cpp
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c=='('||c=='{'||c=='[') st.push(c);
        else {
            if (st.empty()) return false;
            if ((c==')'&&st.top()!='(') ||
                (c=='}'&&st.top()!='{') ||
                (c==']'&&st.top()!='[')) return false;
            st.pop();
        }
    }
    return st.empty();
}
```

---

### 🔹 Sub-pattern 1B: Flexible / Wildcard Parentheses

**Mental model**

* `*` can act as `(` or `)` or empty
* Track **range of possible open counts**

**Recognition**

* Parentheses + `*`
* “can be valid”

**Template**

```cpp
bool checkValidString(string s) {
    int low=0, high=0;
    for(char c:s){
        if(c=='(') low++, high++;
        else if(c==')') low--, high--;
        else low--, high++; // '*'
        if(high<0) return false;
        if(low<0) low=0;
    }
    return low==0;
}
```

### 🔹 Sub-pattern 1C: Scoring / Depth

**Mental model**

* Stack depth represents **structure**
* Empty pair `()` contributes 1, nested doubles

**Recognition**

* “score of parentheses”
* “nesting depth”

**Template**

```cpp
int scoreOfParentheses(string s) {
    stack<int> st;
    st.push(0);
    for(char c:s){
        if(c=='(') st.push(0);
        else{
            int v=st.top(); st.pop();
            st.top() += max(2*v,1);
        }
    }
    return st.top();
}
```

## 🟢 PATTERN 2: Monotonic Stack

### 🔹 Sub-pattern 2A: Next Greater / Smaller Element

**Mental model**

* Stack maintains **monotonic order**
* Breaking order resolves answers

**Recognition**

* “next greater”
* “first element on right/left”

**Template**

```cpp
vector<int> nextGreater(vector<int>& a){
    int n=a.size();
    vector<int> ans(n,-1);
    stack<int> st;
    for(int i=0;i<n;i++){
        while(!st.empty() && a[st.top()]<a[i]){
            ans[st.top()]=a[i];
            st.pop();
        }
        st.push(i);
    }
    return ans;
}
```

---

### 🔹 Sub-pattern 2B: Range Contribution

**Mental model**

* Each element contributes as **min/max** over a range
* Count how far it expands left & right

**Recognition**

* “sum of subarray minimums”
* “contribution technique”

**Template**

```cpp
long long sumSubarrayMins(vector<int>& a){
    int n=a.size();
    vector<int> L(n),R(n);
    stack<int> st;
    for(int i=0;i<n;i++){
        while(!st.empty() && a[st.top()]>a[i]) st.pop();
        L[i]=st.empty()?i+1:i-st.top();
        st.push(i);
    }
    while(!st.empty()) st.pop();
    for(int i=n-1;i>=0;i--){
        while(!st.empty() && a[st.top()]>=a[i]) st.pop();
        R[i]=st.empty()?n-i:st.top()-i;
        st.push(i);
    }
    long long ans=0;
    for(int i=0;i<n;i++) ans+=(long long)a[i]*L[i]*R[i];
    return ans;
}
```

## 🟢 PATTERN 3: Histogram / Rectangle

### 🔹 Sub-pattern: Largest Rectangle

**Mental model**

* Each bar is **minimum height** in its widest span
* Find previous & next smaller

**Recognition**

* “largest rectangle”
* “max area”

**Template**

```cpp
int largestRectangleArea(vector<int>& h){
    h.push_back(0);
    stack<int> st;
    int ans=0;
    for(int i=0;i<h.size();i++){
        while(!st.empty() && h[st.top()]>h[i]){
            int height=h[st.top()]; st.pop();
            int width=st.empty()?i:i-st.top()-1;
            ans=max(ans,height*width);
        }
        st.push(i);
    }
    return ans;
}
```

## 🟢 PATTERN 4: Expression Evaluation / Parsing

### 🔹 Sub-pattern 4A: Reverse Polish Notation

**Mental model**

* Operands first, operator later
* Stack naturally fits

**Recognition**

* “RPN”
* postfix expression

**Template**

```cpp
int evalRPN(vector<string>& t){
    stack<int> st;
    for(auto&s:t){
        if(s=="+"||s=="-"||s=="*"||s=="/"){
            int b=st.top(); st.pop();
            int a=st.top(); st.pop();
            if(s=="+") st.push(a+b);
            if(s=="-") st.push(a-b);
            if(s=="*") st.push(a*b);
            if(s=="/") st.push(a/b);
        } else st.push(stoi(s));
    }
    return st.top();
}
```

### 🔹 Sub-pattern 4B: Infix Calculator

**Mental model**

* Stack stores **context before parentheses**
* Handle precedence manually

**Recognition**

* “basic calculator”
* parentheses + operators

**Template**

```cpp
int calculate(string s){
    stack<int> st;
    int res=0,num=0,sign=1;
    for(char c:s){
        if(isdigit(c)) num=num*10+(c-'0');
        else if(c=='+'||c=='-'){
            res+=sign*num; num=0;
            sign=(c=='+')?1:-1;
        } else if(c=='('){
            st.push(res); st.push(sign);
            res=0; sign=1;
        } else if(c==')'){
            res+=sign*num; num=0;
            res*=st.top(); st.pop();
            res+=st.top(); st.pop();
        }
    }
    return res+sign*num;
}
```

## 🟢 PATTERN 5: Stack as Simulation Engine

### 🔹 Sub-pattern: Collision / Undo

**Mental model**

* Stack = **state history**
* Pop until stable

**Recognition**

* “collision”
* “undo/backspace”

**Template (Asteroid)**

```cpp
vector<int> asteroidCollision(vector<int>& a){
    stack<int> st;
    for(int x:a){
        bool ok=true;
        while(ok && x<0 && !st.empty() && st.top()>0){
            if(st.top()<-x) st.pop();
            else if(st.top()==-x) st.pop(), ok=false;
            else ok=false;
        }
        if(ok) st.push(x);
    }
    vector<int> r(st.size());
    for(int i=r.size()-1;i>=0;i--) r[i]=st.top(),st.pop();
    return r;
}
```

## 🟢 PATTERN 6: Greedy + Stack

### 🔹 Sub-pattern: Remove / Build Optimal

**Mental model**

* Stack keeps **best prefix so far**
* Pop when current choice is better

**Recognition**

* “remove k”
* “lexicographically smallest”

**Template**

```cpp
string removeKdigits(string num,int k){
    string st;
    for(char c:num){
        while(!st.empty()&&k&&st.back()>c){
            st.pop_back(); k--;
        }
        st.push_back(c);
    }
    while(k--&&!st.empty()) st.pop_back();
    int i=0;
    while(i<st.size()&&st[i]=='0') i++;
    string res=st.substr(i);
    return res.empty()?"0":res;
}
```

## 🟢 PATTERN 7: Stack-Based Tree Traversal

### 🔹 Sub-pattern: DFS without recursion

**Mental model**

* Stack replaces call stack

**Recognition**

* “iterative traversal”

**Template**

```cpp
vector<int> inorderTraversal(TreeNode* r){
    vector<int> res;
    stack<TreeNode*> st;
    while(r||!st.empty()){
        while(r){ st.push(r); r=r->left; }
        r=st.top(); st.pop();
        res.push_back(r->val);
        r=r->right;
    }
    return res;
}
```

## 🟢 PATTERN 9: Interval / Chunk Partition

### 🔹 Sub-pattern: Chunk splitting

**Mental model**

* Stack merges overlapping ranges

**Recognition**

* “max chunks”
* “partition array”

**Template**

```cpp
int maxChunksToSorted(vector<int>& a){
    stack<int> st;
    for(int x:a){
        int mx=x;
        while(!st.empty()&&st.top()>x){
            mx=max(mx,st.top());
            st.pop();
        }
        st.push(mx);
    }
    return st.size();
}
```

## 🟢 PATTERN 10: Hybrid (Stack + DP)

### 🔹 Sub-pattern: DP via Monotonic Stack

**Mental model**

* Stack helps choose optimal pairing
* DP cost accumulates greedily

**Recognition**

* “minimum cost tree”
* “optimal merge”

**Template**

```cpp
int mctFromLeafValues(vector<int>& a){
    int res=0;
    stack<int> st;
    st.push(INT_MAX);
    for(int x:a){
        while(st.top()<=x){
            int mid=st.top(); st.pop();
            res+=mid*min(st.top(),x);
        }
        st.push(x);
    }
    while(st.size()>2){
        int mid=st.top(); st.pop();
        res+=mid*st.top();
    }
    return res;
}
```
